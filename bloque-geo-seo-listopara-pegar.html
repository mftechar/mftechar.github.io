Bloque GEO/SEO — Copiar y pegar en mftech-web/index.html

Este bloque cubre las dos recomendaciones prioritarias:

#1 potentialAction #2 G-DATES

1) En el <head> (meta de fecha + JSON-LD WebSite con SearchAction)

Pegá este bloque dentro de tu <head>, junto a los otros <script type="application/ld+json"> que ya tengas.

<!-- G-DATES: fecha de publicación y última actualización (formato ISO 8601) -->
<meta property="article:published_time" content="2026-11-07" />
<meta property="article:modified_time" content="2026-11-07" />
<meta property="og:updated_time" content="2026-11-07" />

<!-- WebSite con potentialAction para agentes de IA (SearchAction) -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "MF Tech AR",
  "url": "https://www.mftechar.com/",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://www.mftechar.com/?search={search_term_string}",
    "query-input": "required name=search_term_string"
  },
  "inLanguage": "es-AR"
}
</script>

2) En el cuerpo visible (<body>) — fecha legible para humanos y bots

Pegá esto donde corresponda en el contenido visible (por ejemplo, cerca del título del artículo o en el pie del artículo principal).

<time datetime="2026-11-07">7 de noviembre de 2026</time>

3) Opcional pero recomendado: Organization con sameAs (Knowledge Graph)

Cuando tengas los perfiles de Wikipedia, Wikidata, LinkedIn empresa y Crunchbase, agregá este bloque también en el <head>:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "MF Tech AR",
  "url": "https://www.mftechar.com/",
  "logo": "https://www.mftechar.com/assets/logo.svg",
  "sameAs": [
    "https://www.linkedin.com/company/mftechar",
    "https://www.crunchbase.com/organization/mf-tech-ar",
    "https://www.wikidata.org/wiki/Q99999999",
    "https://es.wikipedia.org/wiki/MF_Tech"
  ],
  "contactPoint": {
    "@type": "ContactPoint",
    "telephone": "+54-9-2325-406322",
    "contactType": "customer service",
    "availableLanguage": "es"
  }
}
</script>
¿Qué cambiar?
Reemplazá 2026-11-07 por la fecha real de publicación o última modificación de la página. Usá siempre formato AAAA-MM-DD (ISO 8601).
Importante: El bloque de sameAs solo funciona si esos perfiles existen de verdad. Si aún no tenés Wikipedia/Wikidata/Crunchbase, dejá ese bloque comentado o usá solo el de LinkedIn empresa si lo tenés.

4) Dónde pegar todo junto (ejemplo de estructura del <head>)

<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>MF Tech AR — Tecnología que protege y hace crecer tu negocio</title>

  <!-- G-DATES (prioridad #2) -->
  <meta property="article:published_time" content="2026-11-07" />
  <meta property="article:modified_time" content="2026-11-07" />
  <meta property="og:updated_time" content="2026-11-07" />

  <!-- JSON-LD WebSite + SearchAction (prioridad #1) -->
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "WebSite",
    "name": "MF Tech AR",
    "url": "https://www.mftechar.com/",
    "potentialAction": {
      "@type": "SearchAction",
      "target": "https://www.mftechar.com/?search={search_term_string}",
      "query-input": "required name=search_term_string"
    },
    "inLanguage": "es-AR"
  }
  </script>

  <!-- tus otros meta y schemas existentes van acá -->
</head>

Después de subir los cambios a GitHub Pages, recordá hacer Ctrl+F5 en el sitio y verificar con el Rich Results Test de Google que los schemas estén bien leídos.
