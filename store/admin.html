1 · Conexión con GitHub

Cómo crear el token (2 minutos)
  1. Entrá a github.com/settings/personal-access-tokens/new.
  2. Token name: MF Tech Store admin.
  3. Expiration: 90 días (o lo que prefieras).
  4. Repository access → Only select repositories → elegí el repo del sitio.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Generate token y pegalo arriba. Se muestra una sola vez.

El token queda guardado solo en tu navegador y se envía únicamente a api.github.com. No lo compartas ni lo subas al repositorio. Si lo perdés, revocalo y creá otro.
