Gift Codes para tu alianza

Armá el perfil del líder, cargá hasta 100 IDs y canjeá un código para todos los miembros a la vez. La herramienta busca códigos nuevos sola, hasta 6 veces por día.

¿De dónde salen los códigos activos?

La API oficial del juego no publica una lista de códigos. La herramienta consulta el feed público de wosgiftcodes.com, que reúne los códigos anunciados en Discord y redes oficiales. Se muestran con la fecha de publicación cuando está disponible.

¿Cada cuánto busca códigos nuevos?

La lista se actualiza 6 veces al día con una tarea de GitHub Actions, aunque nadie tenga la página abierta. Además, la página revisa cada 4 horas mientras esté abierta y al volver a abrirla.

¿Cómo funciona el canje automático?

Hay dos formas. Con GitHub Actions: descargás el config desde la herramienta, lo subís como giftcodes.config.json y el repositorio canjea cada código nuevo para los IDs indicados, 6 veces al día, sin abrir nada. Con el toggle de la página: usa los IDs guardados en el navegador y el puente de canje. Podés desactivarlo o ignorar códigos puntuales.

¿Cómo canjea el código para 100 IDs?

El perfil guarda los IDs y la región de la alianza. Al tocar “Canjear”, el navegador envía cada ID y el código a un puente propio, que hace la misma llamada que la web oficial del juego. Se procesa de a uno, con una pausa corta para no saturar la API.

¿Es un canje real o una simulación?

Es real cuando el puente está conectado: el estado de cada ID viene de la API del juego (canjeado, ya canjeado, código vencido, ID o región incorrectos). Sin puente no se inventa ningún resultado: la app te avisa y no envía nada.

¿Qué es el estado o región?

Es el número que aparece en tu avatar, arriba a la izquierda del juego. La API lo pide como kid y sin ese dato no puede encontrar al personaje. Todos los miembros de una alianza comparten el mismo estado.

¿Se guarda mi clave?

Nunca en texto plano. Se guarda un hash PBKDF2-SHA256 con sal aleatoria en este navegador. Sirve para bloquear el acceso en este equipo, no como seguridad de servidor. Si la olvidás, no se puede recuperar: hay que borrar el perfil.

¿Qué pasa con mis IDs y mi avatar?

Quedan en localStorage y no se suben a ningún lado. Solo al canjear se envían el ID, la región y el código al puente que configures. Usá tu propio puente para no compartir datos con terceros.

¿Puedo usar el mismo código dos veces?

Sí, pero el juego no entrega la recompensa dos veces. La app muestra “Ya canjeado” cuando la API indica que ese personaje ya lo recibió.
