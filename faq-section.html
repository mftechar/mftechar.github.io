Preguntas frecuentes

¿Qué servicios ofrece MF Tech?

MF Tech ofrece servicios IT para toda Argentina: asistencia remota, instalación de software, cambio de hardware, configuración de servidores, análisis de seguridad de redes, análisis de información, asesoramiento tecnológico, venta de equipos (servidores, PCs, tablets, celulares), cámaras ocultas, equipos anti-espionaje, creación de software a medida y venta de licencias de software.

¿Venden equipos informáticos?

Sí, MF Tech vende servidores, PCs, notebooks, tablets y celulares. También ofrecemos cámaras ocultas y equipos anti-espionaje. Consultá por disponibilidad y precios.

¿Crean software a medida?

Sí, desarrollamos software a medida para empresas y particulares: aplicaciones web, sistemas de gestión, automatizaciones y más. También vendemos licencias de software originales.

¿Venden licencias de software?

Sí, MF Tech vende licencias de software originales: sistemas operativos, antivirus, ofimática, software empresarial, bases de datos y más. Consultá por el software que necesitás.

¿Qué son los equipos anti-espionaje?

MF Tech ofrece equipos anti-espionaje: detectores de cámaras ocultas, detectores de señales RF, y soluciones de contra-vigilancia para proteger tu privacidad y seguridad.

¿Venden cámaras ocultas?

Sí, MF Tech vende cámaras ocultas y dispositivos de vigilancia discreta para seguridad personal y empresarial. Consultá por modelos y disponibilidad.

¿Trabajan en toda Argentina?

Sí, MF Tech brinda servicios IT y asistencia remota para toda Argentina. También realizamos instalaciones presenciales en la zona de Luján y alrededores, y configuración remota de servidores para cualquier parte del país.

¿Qué es la asistencia remota?

La asistencia remota permite que un técnico de MF Tech se conecte a tu computadora a través de internet para resolver problemas, instalar software, configurar sistemas o brindar soporte técnico sin necesidad de desplazamiento.

¿Realizan análisis de seguridad de redes?

Sí, MF Tech realiza análisis de seguridad de redes informáticas, detección de vulnerabilidades, configuración de firewalls, y asesoramiento en ciberseguridad para empresas y particulares.

¿Configuran servidores?

Sí, configuramos servidores Windows y Linux, tanto en infraestructura propia como en la nube (AWS, Azure, Google Cloud). Incluye instalación, configuración de seguridad, backups y monitoreo.

¿Realizan instalación de software?

Sí, instalamos y configuramos todo tipo de software: sistemas operativos, antivirus, ofimática, software empresarial, bases de datos y aplicaciones especializadas. Tanto presencial como remoto.

¿Hacen cambio de hardware?

Sí, realizamos cambio y upgrade de hardware: memoria RAM, discos SSD/HDD, procesadores, fuentes de alimentación, placas de video y más. Diagnóstico previo sin cargo.
