¿De dónde salen los datos del juego?

Las calculadoras usan los valores que cargás vos: costo, tiempo, probabilidad o puntos del evento. Así funcionan igual aunque el juego cambie los números en una actualización.

¿Hay algo pago o un plan Premium?

No. Todas las herramientas son gratis y no tienen versión paga ni funciones bloqueadas.

¿Se guarda algo en un servidor?

Perfiles, formaciones, registros y layouts quedan en el almacenamiento local de tu navegador. Gift Codes usa un puente únicamente cuando tocás “Canjear”: ahí se envían el ID, el código y la región a la API del juego.

¿Qué pasa si borro los datos del navegador?

Se pierden los datos guardados localmente, incluido el perfil de alianza. Exportá el CSV o el respaldo JSON de Gift Codes de vez en cuando.
